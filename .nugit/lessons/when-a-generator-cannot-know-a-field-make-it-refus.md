# Lesson — when a generator cannot know a field, make it refuse visibly instead of substitu…

**Trigger:** nugit's own two-lesson store exported zero eval cases, and the refusal reason on one of them was that its Trigger was the literal commit subject distill had pasted in

**Insight:** when a generator cannot know a field, make it refuse visibly instead of substituting the nearest available string — a plausible wrong value is never reviewed, an empty one is

**Rejected:** synthesizing the symptom with an LLM — the input genuinely does not contain the answer, and an invented observation is unfalsifiable at review time and permanent in the store

**Keywords:** distill, trigger, symptom, lesson, trailers, retrieval
