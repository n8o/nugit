# Lesson — effective status is only as honest as its edges; prose declarations need a lint,…

**Trigger:** a reference kept surfacing as live beside the decision that replaced it, because the supersession was stated only in prose and status derivation reads front-matter edges

**Insight:** effective status is only as honest as its edges; prose declarations need a lint, not a parser

**Rejected:** deriving the edge from prose automatically — a false match would silently supersede a live object; warn keeps the human in the loop

**Keywords:** lifecycle, supersession, prose, front-matter, ADR-0022
