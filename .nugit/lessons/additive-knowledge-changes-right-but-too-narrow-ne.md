# Lesson — additive knowledge changes (right-but-too-narrow) need their own append-only rel…

**Trigger:** a decision was right but too narrow; superseding it would retire a rule that still holds, and editing the file in place would rewrite a record that was already ratified

**Insight:** additive knowledge changes (right-but-too-narrow) need their own append-only relation; supersedes and amends both say something the recurrence case does not mean

**Rejected:** appending a reinforcement section into the target file — mutates an immutable record and recreates same-file merge conflicts

**Keywords:** reinforce, reinforcement, append-only, keywords, retrieval
